# Take a Meep — 开发文档 / Development notes

> 面向开发者的完整说明（中文）。项目主页请看仓库根目录的 [README](../README.md)。

一个常驻 macOS 右下角的 American woodcock 桌面计时搭子（原名 Meep Bird）。名字取自 take a break / take a nap 的双关——到点了，让鸟替你 meep 一声，休息一下。角色外观使用 USFWS 公共领域实拍照片；张嘴后仰节奏与两声提醒音参考用户提供并授权用于本项目的视频素材。

## 已实现

- 透明无边框窗口，默认定位到主屏幕右下角并保持置顶；窗口里**只有鸟和一枚悬浮时间牌**，没有任何面板
- **所有设置都在菜单栏鸟图标里**：点一下菜单栏的小鸟，直接看到当前倒计时状态（`专注中 · 24:12`）和 开始/暂停/继续、重新开始、停止，以及专注时长、休息时长、空闲散步（开关 + 间隔 + 现在走一圈）、静音、**鸟的大小（小/标准/大/超大，整个窗口一起缩放）、透明度（100/85/70/55%，半透明时鼠标悬停会恢复清晰）**、语言、显示/隐藏、回到右下角、退出——全部一层菜单解决
- **双击鸟 = 开始 / 暂停循环计时**（默认专注 30 分钟 + 休息 5 分钟）；单击鸟它只会歪歪头看你；按住拖动把它拎走
- 一枚**细长的胶囊时间牌悬浮在鸟头顶正上方**（不遮住鸟）：**平时是隐形的，鼠标悬停在鸟上就浮现，移开就淡出；单击鸟把它钉住常显，再单击一次收起**（鸟每次都会歪头回应）；显示剩余时间（专注橙色 / 休息绿色，空闲时显示 Ready），散步时也跟着；牌子前端横排三颗小圆钮：**⏸ 暂停/继续、↺ 重新开始、■ 停止**（空闲时后两颗禁用），尾端还有一颗**小鸟头按钮，点一下它就 meep 给你听**；鸟鸣提醒进行中时间牌也会自动亮起
- **散步只发生在休息时段和完全空闲时**：专注计时中和暂停中绝不会出门，只做环顾、理毛、摇摆之类的小动作；休息时段的散步由计时安排；"空闲散步"指没有任何计时进行时的日常遛弯，可以在菜单里关掉
- 专注结束：鸟连叫约 5 秒 `meep meep`，然后把整段休息时间用来出门散步——**散步计划按剩余休息时长精确编排、毫秒级准点回到出发点**：休息久，路上每次驻足摇摆的时间会变长（最多 6.5 秒/次）、折返点也更远（最多约 55% 屏宽），多出来的时间在远端觅食（啄地、理毛、摇摆）；休息短则先压缩摇摆（最短 1.2 秒/次），还不够就把折返点拉近；休息结束轻叫一声，自动进入下一轮专注，循环往复
- **按住鸟拖拽**可以把它拎到屏幕任何地方：被拎起时身体后仰、两腿悬空乱蹬、尾巴张开；松手后受重力掉回屏幕底部，落地时蹲一下、抖抖羽毛，然后就在新位置安家（散步也从那里出发、再走回来）。菜单栏里有“回到右下角”
- 时间到后自动显示窗口，播放两声 `meep`：头部大幅后仰（约 35°）、下喙张开近 30°、身体鼓起、尾羽张开，两次；喙缝里能看到背景，只有嘴角处是暗色口腔
- **叫声重制过**：从原视频音频做了两遍谱减降噪 + 260 Hz 高通 + 7.6 kHz 低通（叫声谐波都在 7 kHz 以下，之上全是嘶声），间隙彻底静音——原来 −30 dB 的底噪现在听不到了；并做了三个变体（清理原声 / 换序略升调 / 整体低沉），每次鸣叫随机挑一个（不会连续重复），听起来不像循环采样
- 空闲时默认每 15 分钟在屏幕底部散一次步：按真实 woodcock 的节奏，慢走 3–7 步 → 停下原地前后摇摆 → 再走，走到头转身回家。两条腿真的在迈步（支撑脚钉在地面上不打滑，摆动脚只在身体前冲时抬起），整个身体大幅前后摇摆、前冲时低头，头跟随约 85% 的摆动、其余由脖子伸缩吸收——这些比例来自对 USFWS 行走视频的逐帧追踪
- 空闲时随机做小动作：环顾四周、朝鼠标方向歪头、原地 woodcock 招牌摇摆、低头理胸前的羽毛、俯身用长喙啄地探土、向后伸腿、抖毛，随机眨眼；4 分钟没人理会就缩着脖子闭眼打盹，鼠标靠近或点击就醒
- 角色采用照片驱动的 2.5D puppet（v4）：头、可拉伸的脖子、身体、近侧翅膀、上下喙、两条腿（跗跖 + 脚趾）、尾羽、眼睑共 12 个图层，全部像素来自同一张实拍照片；脖子是独立的一段（身体→脖子→头三级链），走路伸缩、低头、后仰都有平滑的颈部过渡
- 用鼠标在鸟身上来回摩擦可以摸摸它：它会眯眼、蓬起羽毛、朝你的手蹭过来、摇尾巴，摸得久了头顶冒小心心；**一直摸下去（4 秒以上）它会开心得仰头 `meep meep` 叫两声**（之后要缓十几秒才会再叫）
- 鼠标停在鸟嘴前方不动一会儿，它会伸长脖子好奇地啄一两下
- 从高处松手时会快速扑棱翅膀（woodcock 式的短促高频振翅），下落速度也会被拍打减慢
- 界面默认英文，菜单栏 Language 子菜单一键切换中文（含整个菜单），选择会保存
- 所有设置和运行中的截止时间会保存在本机


## 打包 macOS 应用

```bash
npm run icon          # 生成 app 图标（晨光渐变圆角方块 + 实拍鸟，Big Sur 网格）
npm run package:mac
```

生成结果：

```text
dist/Take a Meep-darwin-arm64/Take a Meep.app
```

应用使用本机 ad-hoc 签名，适合在当前 Mac 上直接运行；它没有 Apple Developer ID 公证签名，因此分发到别人的 Mac 时仍可能出现 Gatekeeper 提示。

## 角色 puppet 是怎么做的（v4）

`tools/make_photo_puppet_v4.py` 把 `assets/character/idle-v2.png`（1600×893 的实拍抠图）切成 `assets/character/puppet-v4/` 里的图层，并生成 `manifest.json` / `manifest.js`（各图层在原图中的位置、所有关节的坐标）。所有 RGB 像素都直接来自照片，脚本只负责 alpha 蒙版、几条藏在身体后面的克隆条带，以及嘴角处的暗色口腔：

- **喙**：按 alpha 通道拟合喙的上下缘和嘴裂线，上喙层带一小片额部羽毛、下喙层带一块下巴/喉部羽毛（当作下颌），各自绕铰点旋转。头层里喙原来的位置只在嘴角附近 ~80 px 涂成口腔色，其余透明——这样张嘴时既没有闭合喙的残影，喙缝里也能看到背景。
- **头/颈**：v4 把脖子切成独立图层：头只含头骨（柔边领口），脖子是一条覆盖后颈和喉部的柔边条带，渲染时按“肩上的颈根 → 头下的颈顶”两点做拉伸+旋转贴合（伸缩限制在 0.72–1.3 倍），头再挂在颈顶上并继承约一半的颈部弯曲，身体层仍保留一小块“颈桩”备用；低头理毛、啄地、后仰鸣叫时颈部都是连续的。
- **翅膀**：近侧折叠翅膀整块复制成单独图层，绕肩部铰点旋转；它盖在身体上，抬起时身体上原有的翅膀像素正好成为远侧翅膀——扑棱时看起来是两只翅膀。
- **腿**：所有在腹部羽毛边缘以下的像素都是腿；分成两条跗跖和两只脚，跗跖沿着自身轴线可拉伸，运行时用髋 → 膝（隐藏）→ 跖关节的两段式 IK 摆放。
- **尾**：照片里尾巴几乎被翅尖挡住，因此把可见的那根带横纹的尾羽单独切出来并向根部延长，渲染时叠 4 份并按“张开度”扇形展开，静止时也能看到一小截尾巴，叫声和摇摆时会张开。
- **眼睑**：从眼下的颊部羽毛采样一块圆形贴片，用来眨眼和打盹。

改完脚本后重新生成：

```bash
npm run puppet
```

（`tools/make_photo_puppet_v3.py` 与旧的 `assets/character/puppet-v3/` 保留作参考，不再被应用使用。）

## 动作参考

- 走路节奏取自 USFWS 的公共领域行走视频（`assets/source/usfws-woodcock-walk.webm`）。v0.4 对它做了带相机补偿的逐帧追踪（眼睛模板匹配 + 身体色块质心 + 背景相位相关）：整只鸟前后摇摆的峰-峰幅度约为体长的 13%，前冲时俯身、后摇时抬头；眼睛跟随约 85% 的摆动、每个周期还垂直起伏约体长的 6–7%；迈步只发生在前冲段。这些数字直接写进了 `updateWalk`。“走几步停下摇几下”的模式来自 10,000 Birds 与 Birdshow 等的觅食行走描述；鸟类 head-bobbing 的 hold/thrust 与步态同步机制参考 Frontiers in Zoology (2014) "On vision in birds: coordination of head-bobbing and gait"。
- 扑棱翅膀参考 woodcock 惊飞时的振翅方式（短圆的翅膀快速浅拍、外侧三根初级飞羽发出啸音）：坠落时以约 9.5 Hz 浅幅拍打，下落速度被拍打限制。
- 叫声姿态沿用用户视频里抠出的 `assets/character/call-v2-clean/` 序列：头后仰、喙大幅张开、身体鼓起，两声之间头部只回落一半。

## 素材与实现说明

多个不同 YouTube 视频中的活动鸟不满足严格摄影测量或 NeRF 的条件：重建需要同一个静止主体、稳定表面和可对应的多角度画面。当前版本因此采用照片驱动的 2.5D puppet，优先保证真实羽毛与可爱的轮廓；如果之后取得同一标本的合法多视角照片或带骨骼 GLB，可以沿用现有走路、转身、拖拽和叫声时间线。

`assets/character/puppet-v4/` 和 `assets/audio/` 是应用运行所需的精简派生素材。`VideoFrames/`、`assets/source/` 以及旧版 `puppet-v2` / 帧序列目录是可重新生成的本地中间文件，默认不会进入 Git 或应用包。`src/renderer/woodcock-rig.js` 是早期的 three.js 程序化模型，当前未被使用。

具体来源与许可见 [`assets/ATTRIBUTION.md`](assets/ATTRIBUTION.md)。用户提供素材及其派生音频的进一步公开发布、商用或转授权仍应遵循用户拥有的原始许可。
